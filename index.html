1. Introduction to Computing: Historical Timeline

Computing developed over many centuries. The following milestones show how calculation tools evolved into modern computers.

Ancient Times

The Abacus

The abacus is an early calculating tool used to perform arithmetic operations such as addition and subtraction.

1642

Pascaline

Blaise Pascal developed a mechanical calculator that could perform addition and subtraction.

1837

Analytical Engine

Charles Babbage designed the Analytical Engine, an important early design for a general-purpose programmable computer.

1940s

Electronic Computers

Computers such as ENIAC used electronic components to perform calculations much faster than many earlier machines.

1970s–1980s

Personal Computers

Microprocessors helped make computers smaller and more affordable for individuals, schools, and businesses.

1990s–Today

Internet and Modern Computing

Internet services, smartphones, cloud computing, and artificial intelligence have transformed how people use technology.

Why is computer history important?

Studying computer history helps us understand how earlier inventions influenced modern hardware, software, communication, and information processing.

2. Parts of a Computer

A desktop computer system includes several devices that work together to accept input, process data, store information, and produce output.

Output Device

Monitor

Displays text, images, videos, and other visual information from the computer.

Processing

System Unit

Houses important components such as the CPU, motherboard, memory, storage, and power supply.

Input Device

Keyboard

Allows users to enter letters, numbers, symbols, commands, and other data.

Input Device

Mouse

Controls the pointer and allows users to click, select, drag, and interact with graphical interfaces.

Output Device

Speakers

Produce sound from music, videos, applications, and other audio sources.

Output Device

Printer

Produces physical copies of digital documents, pictures, and other files.

Portable Computer

Laptop

A portable computer with an integrated display, keyboard, pointing device, battery, and internal components.

Audio Output

Headphones

Allow a user to listen to computer audio without using external speakers.

3. Internal Parts of the System Unit

These internal components perform the main computing, memory, storage, power, and cooling tasks.

CPU

The Central Processing Unit executes instructions and performs calculations. It is often called the computer's brain.

RAM

Random Access Memory temporarily stores data and instructions currently in use. Its contents are normally lost when power is removed.

Storage Device

HDDs and SSDs store the operating system, programs, and files for long-term use.

Graphics Processing Unit

The GPU processes graphics and parallel workloads. It can be integrated into a processor or installed as a separate card.

Power Supply Unit

Converts electricity from an outlet into the power required by computer components.

Cooling System

Fans and heatsinks help remove heat and keep components within safe operating temperatures.

4. Parts of the Motherboard

The motherboard is the main circuit board of a computer. It connects the processor, memory, storage, expansion cards, and other components.

What does a motherboard do?

It provides electrical connections and communication pathways between compatible hardware components. The exact layout varies by motherboard model.

1. CPU Socket

Holds the processor. The socket must match the supported CPU family.

2. RAM Slots

Hold memory modules used for temporary storage of active data and instructions.

3. Chipset

Helps manage communication and connectivity between supported components and interfaces.

4. PCI Express Slots

Connect expansion cards such as graphics, network, and sound cards.

5. SATA Connectors

Connect compatible SATA storage devices such as hard drives and SATA SSDs.

6. M.2 Slot

Supports compatible M.2 devices, including NVMe SSDs and, on some boards, other supported modules.

7. Power Connectors

Receive power from the power supply for the motherboard and processor.

8. BIOS / UEFI Firmware

Initializes hardware and helps start the operating system during boot.

9. CMOS Battery

Helps maintain the real-time clock and certain firmware settings when the computer is powered off.

10. Rear I/O Ports

Provide external connections such as USB, audio, Ethernet, and display ports, depending on the board.

Important motherboard reminder

Not every motherboard has the same components, connectors, or arrangement. Always check the motherboard manual before installing hardware.

5. Hardware and Software

A computer system needs physical equipment and software instructions to perform useful tasks.

Hardware

Hardware refers to the physical parts of a computer that can be touched.

Examples: CPU, monitor, keyboard, RAM, mouse, and motherboard.

Software

Software consists of programs and instructions that tell a computer how to perform tasks.

Examples: Windows, Linux, web browsers, text editors, and games.

Types of software

System software: Operating systems and utilities that manage the computer.

Application software: Programs used to complete tasks, such as writing documents, browsing the internet, or editing images.

Programming software: Tools used to write, test, and maintain computer programs.

6. The IPO Cycle

Computers commonly receive input, process data, produce output, and may store results for later use.

Step 1

Input

Data is entered using a keyboard, mouse, scanner, microphone, or other input device.

Step 2

Processing

The CPU executes instructions to process data according to a program.

Step 3

Output

Results are presented through a monitor, printer, speakers, or another output device.

Step 4

Storage

Data and results can be saved on an SSD, hard drive, USB drive, or other storage medium.

Example: Calculating student grades

Input: Enter examination scores.

Processing: Calculate the average using a program.

Output: Display the final grade.

Storage: Save the result in a file or database.

7. Data and Information

Data

Raw facts and values that have not yet been organized into meaningful information.

Example: 85, 90, 95.

Information

Data that has been processed or organized so that it has meaning.

Example: The average of 85, 90, and 95 is 90.

Common forms of digital data

Text, numbers, images, audio, video, and computer instructions can all be represented and processed digitally.

8. Number Systems in Computing

Computers represent and process data using digital signals. Different number systems are useful for understanding those representations.

Number System Base Symbols Used Example
Binary 2 0, 1 1010
Octal 8 0–7 12
Decimal 10 0–9 10
Hexadecimal 16 0–9 and A–F A

Example conversion

Binary 1010 equals decimal 10.

Calculation: (1 × 8) + (0 × 4) + (1 × 2) + (0 × 1) = 10.

9. Computer Networks and the Internet

A computer network connects devices so they can communicate and share data or resources.

LAN

A Local Area Network connects devices within a limited area, such as a computer laboratory, office, or school.

WAN

A Wide Area Network connects networks across large geographical areas.

Internet

The internet is a global network of interconnected networks that supports websites, email, online learning, and many other services.

10. Computer Safety and Responsible Use

Computers should be used safely, responsibly, and ethically.

Protect Your Accounts

Use strong, unique passwords and never share them with others. Enable multifactor authentication when available.

Avoid Suspicious Links

Check links and downloads carefully. Do not open unexpected attachments or provide information to suspicious websites.

Handle Hardware Properly

Keep liquids away from equipment. Shut down the computer before installing internal components, and follow safety instructions.

Practice Digital Ethics

Respect privacy, follow copyright rules, avoid cyberbullying, and use technology responsibly.
